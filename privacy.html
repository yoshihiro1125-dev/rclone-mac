プライバシーポリシー

最終更新日: 2026年10月18日

  • rclone-mac は、作成者本人が自分の Google アカウントで使うための設定です。
  • 許可された Google ドライブのファイルとその情報(ファイル名・大きさ・更新日時)を読み取り、本人のパソコンへ写すためだけに使います。
  • 読み取ったデータと認証情報は本人の端末にだけ保存され、作成者が運営するサーバーへ送られることはありません。
  • データを第三者へ提供・販売・共有することはありません。広告や分析には使いません。
  • Google API から受け取った情報の利用と他のアプリへの受け渡しは、Google API Services User Data Policy(Limited Use の要件を含む)に従います。
  • 許可はいつでも Google アカウントのサードパーティ アクセス から取り消せます。

Privacy Policy

Last updated: October 18, 2026

  • rclone-mac is a configuration used only by its owner with the owner's own Google account.
  • It reads the Google Drive files and their metadata (names, sizes, modification times) that the user authorizes, solely to copy them to the user's own computer.
  • Data and credentials are stored only on the user's own devices and are never sent to any server operated by the owner.
  • No data is sold, shared with, or transferred to third parties, and none is used for advertising or analytics.
  • Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at Google Account third-party access.
