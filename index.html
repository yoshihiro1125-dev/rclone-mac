rclone-mac

rclone-mac は、オープンソースのファイル同期ツール rclone を個人で使うための Google API の設定です。 作成者本人が、自分の Google ドライブのファイルを自分のパソコンへ写して保管するためだけに使います。一般向けのサービスではありません。

rclone-mac is a Google API client configuration for personal use of the open-source tool rclone. It is used only by its owner to copy the owner's own Google Drive files to the owner's own computer. It is not a public service.
